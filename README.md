# Webinar sobre IA con registro:
Aplicación web para el registro de asistentes a un webinar sobre la IA, el proyecto cuenta con una interfaz de registro, almacenamiento de los registros en Google Sheets y envío automático de un correo de confirmación al usuario.

**Sitio web:**
https://webinar-con-registro.onrender.com


## Se utilizó para el desarrollo:
* HTML5
* CSS3
* JavaScript
* Node.js
* Express
* Body Parser
* CORS
* Google Sheets API
* Google Cloud Service Account
* Resend API
* Render
* Git
* Github
